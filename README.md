AIS-RS
======

Crate for working with AIS messages as defined by [ITU-R M.1371-6 (02/2026)](https://www.itu.int/rec/recommendation.asp?lang=en&parent=R-REC-M.1371-6-202602-I), including application-specific messages.

The application-specific messages are those registered in the [IALA ASM collection](https://www.e-navigation.nl/asm) kept by the Netherlands, which links each message's specification; each type in `ais_asm` names its entry.
